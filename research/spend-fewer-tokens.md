## Confirmed
- Why usage climbs: C costs, section "Why usage climbs in a long session". Full conversation sent with every request; each tool use sends another request; cache misses after a break longer than the cache lifetime; subagents and agent teammates send their own requests; `/compact` reads the conversation it summarises; `/clear` costs nothing. Also lists scheduled tasks, cross-session messages and goal check-ins (not taught).
- Habits list: C costs, "Reduce token usage": `/clear` between tasks with `/rename` first; `/compact` with focus instructions; Sonnet handles most tasks, `model: haiku` for simple subagents; MCP tool definitions are deferred, so names and server instructions load, `/context` shows what takes space, `/mcp` to disable unused servers; keep CLAUDE.md under 200 lines; thinking tokens are billed as output tokens, lower with `/effort`; delegate verbose operations to subagents, whose own requests still draw on usage; specific prompts. Large logs example: "a 10,000-line log" (hooks filtering is on the page but not taught here).
- `/usage`: C costs, "Using the /usage command". Session block is "intended for API users"; subscribers see plan usage bars, activity stats and a breakdown. Dollar figure is computed locally at list price. Totals reset on `/clear` (from v2.1.211). The plan breakdown recommends a change for behaviours behind 10% or more of recent usage. "rate limited until ..." means plan limits cannot be fetched, not that work is limited. A "Prompt cache (main)" line needs v2.1.251 or later and shows share from cache and warm or cold.
- Cache: C prompt-caching. Prefix match, whole request re-sent each turn. TTL table: main conversation one hour on a Claude subscription within plan usage; five minutes with usage credits, API key or cloud provider. Actions that invalidate the cache: switching models, changing effort (not on Fable 5.1 and later, Opus 5.5, Sonnet 5.5 or Haiku 5.5 with an API key or subscription), fast mode, connecting or removing an MCP server, enabling or disabling a plugin, denying an entire tool, compacting, many images, upgrading Claude Code. Each model has its own cache. "Pick your model and effort level at the top of a session, then save /compact for natural breaks between tasks." `/compact` warm costs a fraction of the context size; cold (after the lifetime) it reprocesses the history uncached, "costs the most when you resume an old session". Idle compaction on the one-hour TTL can be turned off with `idleCompaction` (v2.1.290 or later; not taught).
- Commands: C commands. `/compact [instructions]`, `/context`, `/clear` and `/usage` exist as described.
- OpenCode: O config page, section Compaction: `compaction` with `auto`, `keep.tokens` and `buffer` (share of the context window kept free before automatic compaction). Not confirmed: slash-command names for new session and compaction. The earlier note (research/session-management.md, 2026-11-16) recorded `/new` (alias `/clear`) and `/compact` (alias `/summarize`) on the TUI page. On 2026-11-28 the TUI page lists `/new`, `/sessions`, `/models`, `/agents`, `/undo`, `/redo` and `/editor` and no `/compact`, so the page tells readers to run `/help` and does not name a compaction command.
- Ollama `ollama ps` columns CONTEXT and SIZE: carried over from The Context Window (not re-run here).
