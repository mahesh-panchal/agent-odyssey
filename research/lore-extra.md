# Lore extra sources

URLs the Lore lint (`tools/lint_lore.py`) accepts in addition to those in other `research/*.md` files: supplied by the maintainer or read by the team. One URL per entry; add a note on who supplied it and what it is.

- https://github.blog/ai-and-ml/github-copilot/build-once-run-on-any-agent-a-practical-guide-to-agent-skills/ : "Build once, run on any agent: a practical guide to agent skills", Andrea Griffiths, GitHub Blog, 2026-11-12. Supplied by the maintainer; read 2026-11-17 (see `skills-portability.md`).
- https://docs.github.com/en/copilot/how-tos/copilot-on-github/customize-copilot/customize-cloud-agent/add-skills : "Add an agent skill to GitHub Copilot", GitHub docs. Linked from the article above; not read by us.
- https://github.com/githubevents/build-once-run-on-any-agent : demo repository for the article (demos: proof-agent, dataforge). Linked from the article above; not read by us.

- https://code.claude.com/docs/en/sub-agents : Sub-agents, Anthropic docs. Already cited in research/forest-and-reef.md; spot-checked 2026-11-17 for `model`, `effort`, `tools` frontmatter, model resolution order and the Explore/Plan CLAUDE.md skip (first ~100k characters of ~116k read). Used in Lore for Pick Your Companion.
- https://claude.dev/blog/which-claude-model-should-you-build-with/ : claude.dev blog article, 2026-11-09, byline as shown on the page (not verified); the source of the model-choice ideas in research/model-and-effort.md section 9. Secondary; not in Lore.
- https://www.aihero.dev/what-are-evals : "Your App Is Only As Good As Its Evals", AI Hero, last updated 2024-11-18 (author not verified). Supplied by the maintainer; read 2026-11-20 via a fetch summary, not first-hand. Source of the three grader kinds (deterministic, human, judge model), pass/fail versus score, and dataset points in the "What is an eval?" section of Close the Loop. Secondary; written for app builders.
- https://www.ibm.com/think/topics/generative-ai-vs-predictive-ai-whats-the-difference : "Generative AI vs. predictive AI: What's the difference?", IBM Think, byline Rina Diane Caballar, published 2024-08-09. Supplied by the maintainer; read 2026-11-20 via a fetch summary, not first-hand. Source of the generative versus predictive note in Three Kinds of Machine. Secondary; vendor marketing-style explainer.

- https://arxiv.org/abs/2603.18507 : "Expert Personas Improve LLM Alignment but Damage Accuracy: Bootstrapping Intent-Based Persona Routing with PRISM", Hu, Rostami, Thomason, arXiv, submitted 2026-03-19 (v1). Read 2026-11-20: abstract page first-hand via fetch; length and model details partly from a summary of the full text. Source of the persona note in Write the Brief. Confirmed: personas help alignment-type tasks, hurt knowledge tasks (MMLU 71.6% base vs 68.0% shortest persona); shorter personas reduce but do not remove the damage; longer ones help alignment more. Tested only 7-8B open models. Did NOT test flattery or "world's best" wording; the Reddit claim about under-50-token identities is not supported by it. Preprint.
- https://arxiv.org/abs/2512.08296 : "Towards a Science of Scaling Agent Systems", Kim et al. (Google Research, Google DeepMind, MIT), arXiv, v1 2025-12-09, v3 2026-04-08. Read 2026-11-20: abstract and first ~40k characters of v3 first-hand via fetch; later sections from a summary. Source of the multi-agent note in Too Many Tools, Too Many Agents. Confirmed (v3): 260 configurations, six benchmarks, single agent vs four multi-agent architectures; about 45% single-agent baseline then negative returns; sequential planning -39% to -70%; decomposable finance up to +80.8%; independent agents amplify errors 17.2x vs 4.4x centralized. Numbers differ between versions. The "7x tokens for 3.1x output" claim from the Reddit post was NOT found; the paper reports different cost figures (unverified, from a summary). Preprint.
- https://unsloth.ai/docs/get-started/fine-tuning-llms-guide : "Fine-tuning LLMs Guide", Unsloth docs, no date shown (author n/a). The old URL docs.unsloth.ai/get-started/fine-tuning-llms-guide redirects (301) here. Read 2026-11-20 via a fetch summary, not first-hand. Source of the LoRA note in Three Kinds of Machine: LoRA trains small adapters on frozen weights, QLoRA is LoRA on 4-bit weights, a question-answer dataset with a held-out test split. Vendor product docs; its speed and "3GB VRAM" claims are the vendor's and were not checked. The summary says local install needs Windows or Linux.
- https://huggingface.co/docs/peft/main/en/conceptual_guides/lora : "LoRA", Hugging Face PEFT docs (main branch; stable was v0.22.0 when read). Read 2026-11-20 via a fetch summary, not first-hand. Source of the LoRA note in Three Kinds of Machine: frozen original weights, two small low-rank update matrices, `r` and `lora_alpha`, adapters merged with `merge_and_unload()`. The "when to fine-tune" criteria in that note are general practice, not from either page.
