Background

This page explains how Agent Odyssey is laid out. Agent Odyssey is a short role-playing course on using coding agents (LLM tools that read and run code for you) safely in bioinformatics work. You need no LLM experience, and nothing here asks you to use these tools. It shows how to use them with care if you choose to.

Before you begin

There is nothing to do yet. The exercises use a terminal, Python 3 and git, and each lesson says when it first needs one. You install an agent in Set Up Your Agent, a few lessons in, and the Prerequisites page lists every tool and how to check it.

Your path

Who is who

The story uses a few names. The lessons themselves use plain technical words.

  • Shokanju: the umbrella word for every creature you can summon, from scripts to language models.
  • Automata: clockwork creatures. Scripts and pipelines: obedient, the same every time, and brittle when the road changes.
  • Familiars: creatures trained for one task. Classical machine-learning models.
  • Astrals: spirits that speak every tongue. Language models and the coding agents built on them. Generous, fast and unbound from physical reality, so they invent when unchecked.
  • The pact: summoning and binding an Astral, which is installing and starting a coding agent. The binding circle is the harness, the wards are permission rules and the sandbox, and the terms of the pact are the instructions file.
  • The Blight: plausible but false output that spreads when nobody checks it.

How it works

  • Walk the trunk. It is 16 quests in order, from fears and kinds of machine to your first agent and trust in output. The boss, Review Large Output, ends it.
  • Pick branches. Each branch is a topic you can take when it matches your work. Quests marked side quest are optional.
  • Review a Messy Session. The final boss opens after the whole trunk and any 3 of the 8 branches.
  • Save your progress. It lives in this browser. Save code in the top bar copies a code, and Load code restores it elsewhere.

The trunk takes about three hours and each branch one to two more. The order is advice, and every quest stays open.

Keep exploring

This course covers a small part of what these tools can do. The Claude Code docs are the best place to learn more, and each quest’s Lore section links the pages that matter for it. Browse the overview whenever you are curious.

For research-specific guidance, AI for Science collects draft best practices for agentic AI in science from European task forces and institutions, and has a one-page short version. The practices are drafts with no endorsements yet, and several are written for institutions and funders. Nine quests draw on one practice each: Script, Model, or LLM, Advice or Enforcement, Keep Secrets Out of Reach, Turn Mistakes into Tests, Ground Truth, Connect an MCP Server, Block Actions with a Hook, Boss: Review Large Output and Write an Instructions File.
